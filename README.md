### 📝 Présentation du projet 
**Hub Gaming** est une application web dynamique et responsive connectée à l'API REST de **RAWG**. Elle permet aux passionnés de jeux vidéo de rechercher des titres parmi une base de données massive, de consulter leurs fiches détaillées (notes, genres, plateformes) et de gérer une liste de favoris persistante.

### ⚡️ Fonctionnalités clés implémentées
* **Recherche asynchrone performante :** Prise en compte au clic et de la touche `Entrée` pour un confort utilisateur (UX) optimal.
* **Système de Favoris Autonome :** Sauvegarde et persistance des choix de l'utilisateur directement dans le navigateur via le `localStorage`.
* **Modales dynamiques :** Affichage riche des détails techniques d'un jeu (genres, plateformes, notes) sans rechargement de page.
* **Interface Modern UI :** Design épuré, asymétrique et entièrement responsive (Mobile, Tablette, PC).

### 📐 Architecture & Structure du code (Clean Code)
Le projet applique une séparation stricte des concepts pour garantir la maintenabilité, se rapprochant de la logique MVC:
* 📁 `js/api.js` : Gestion exclusive des requêtes HTTP réseau de l'API RAWG (Fonctions asynchrones autonomes).
* 📁 `js/dom.js` : Manipulation du DOM, création dynamique des composant HTML (cartes, fenêtres modales) et gestion du `localStorage`
* 📁 `js/app.js` : Chef d'orchestre de l'application (initialisation, écouteurs d'événements globaux et liant technique).

### 🛠️ Défis techniques relevés & acquis
* **Optimisation des performances :** Utilisation de `Promise.all` pour paralléliser les requêtes d'API lors du chargement des favoris afin d'éviter les ralentissements.
* **Gestion fine de l'asynchronisme :** Traitement des acs d'erreurs (Erreur HTTP 401, conflits CORS) et reformatage à la volée (*mapping*) des objects de l'API pour les aligner avec le rendu graphique.
* **Workflow professionnel :** Gestion rigoureuse des versions et du cache avec Git/GitHub via des commits atomiques et explicites.
